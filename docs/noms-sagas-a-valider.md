# Noms français de sagas à valider

> Généré le 2026-10-05 par `scripts/proposer-noms-sagas.mjs`. **Kinder** : cochez ce que vous validez (ou dites-moi « tout sauf … »), corrigez le nom français si besoin.
> Un nom validé est enregistré par `npm run corriger -- serie <id> --nom-fr "<nom>"` : la saga s'affichera sous ce nom ET répondra à une recherche de ce nom.
